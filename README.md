# Платформа для локальных мастеров

«Домашний помощник» — учебное клиент-серверное веб-приложение для выбора бытовой услуги и ведения заявки от обращения до подтверждения результата. Клиентские страницы работают через API FastAPI; связанные данные хранятся в SQLite.

Репозиторий содержит рабочую версию страниц и ресурсов, проверенную на `domashniypomoshnik.ru` 24.10.2026, серверный код и интеграционные тесты. Отдельный незавершённый эксперимент с анимированной главной страницей в релиз не включён. Рабочая база, загруженные пользователями файлы, резервные копии и старые скрипты с внешними интеграциями в репозиторий не входят.

## Возможности

- Заказчик выбирает услугу в каталоге, отправляет заявку, отслеживает статус, переписывается с назначенным мастером, подтверждает завершение и оставляет отзыв.
- Мастер заполняет анкету, услуги, график и портфолио, получает назначенные заявки и отмечает ход работы.
- Администратор модерирует анкеты и отзывы, назначает исполнителей и отвечает на обращения в поддержку.
- Дополнительно предусмотрено прямое бронирование мастера. Повторная отправка формы с тем же ключом не создаёт дубль заявки.

Реальных платежей, SMS и проверки документов мастеров нет. Интерфейс и демонстрационные данные предназначены для защиты курсовой работы, не для приёма реальных заказов без отдельной эксплуатационной подготовки.

## Локальный запуск

Нужен Python 3.11 или новее. В корне репозитория:

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r platform/requirements.txt
.venv/Scripts/python platform/app.py --demo --port 8765
```

На Windows приложение будет доступно по `http://127.0.0.1:8765/`. Параметр `--demo` создаёт отдельные учебные записи; не используйте эту базу для реальных пользователей. Для пустой базы сначала запустите `python platform/manage.py --database <путь-к-БД>` и задайте администратора в интерактивном режиме без передачи пароля в аргументах.

## Проверка

```bash
.venv/Scripts/python -m pytest platform/tests -q
```

Тесты создают собственные временные SQLite-базы. На 24.10.2026: 13 тестов прошли, в том числе основной цикл заявки, разграничение доступа, чат, модерация, прямое бронирование и доступность ресурсов всех страниц.

## Структура

- `Code/` — десять HTML-страниц, стили, браузерная логика и изображения.
- `platform/app.py` — страницы, API, роли, валидация, сессии и операции с заявками.
- `platform/schema.sql`, `catalog.json` — схема и каталог услуг.
- `platform/manage.py`, `seed.py` — инициализация и отдельное демо-наполнение.
- `platform/tests/` — интеграционные проверки.

Секреты и рабочие данные не должны попадать в Git. Перед реальным размещением нужны отдельные настройки HTTPS, резервного копирования, прав доступа и обработки персональных данных.
